MOHIT ULTRA PREMIUM GAMING PORTFOLIO
=======================================

Included:
- index.html
- style.css
- script.js
- thank-you.html
- README.txt
- videos/ folder

IMPORTANT:
1. Put your existing "mohit-photo.jpg" beside index.html.
2. Add your own MP4 gameplay clips inside videos/ when ready.
3. The Challenge form asks for Game Name, Username, Game UID, Instagram and Challenge Message.
4. Contact and Challenge forms preserve the FormSubmit destination:
   mohitbishnoi7568@gmail.com
5. _next points to the GitHub Pages thank-you page.
6. Dark/light preference is stored in browser localStorage.
7. No fake gaming achievements or stats are included.

VIDEO SETUP:
The current video cards are lightweight placeholders so the ZIP stays small.
You can replace each placeholder with your own video player later using:
videos/gameplay-1.mp4
videos/gameplay-2.mp4
videos/gameplay-3.mp4

DEPLOY:
Upload all files to the root of your GitHub Pages repository, keeping
mohit-photo.jpg in the same folder as index.html.
